USE CASES

学校行事の「ねらい」に合わせて活用

学年づくり、クラスづくり、行事前の関係づくりなど、課題に合わせてご活用ください。

修学旅行 / 宿泊研修
旅行中の学びの時間として

観光や自由行動だけでは得にくい、対話・協力・振り返りの時間を行程に組み込めます。

入学式 / 新学期オリエンテーション
初対面の生徒同士が、早期に関係性をつくる

初対面でも自然に打ち解け、クラスや学年のまとまりを最初期に形成するのに最適です。

体育祭 / 文化祭の前
学校行事前のチームビルディングとして

行事の前にチームワークを高めることで、本番での協力・団結力が格段に向上します。

部活動
チームワーク向上のきっかけづくり

いつもの部活では見えなかった一面が引き出され、相互理解が深まります。

探究学習 / キャリア教育
主体性や自己理解を育む学習の場として

自分の考えを言語化し、互いの価値観から新しい気づきと学びを得る機会を提供します。

林間学校 / 遠足
クラスの関係性を再構築したいときに

アクティビティと振り返りを通じて、互いを理解・認め合える空気をつくります。
